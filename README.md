# YT-Play

A lightweight web-based application built with HTML and JavaScript designed to play and interact with YouTube media directly in your web browser.

## 🚀 Live Demo

Check out the live web app hosted on GitHub Pages:
👉 **[Launch YT-Play](https://diptarafder17-prog.github.io/YT-Play-/)**

---

## ✨ Features

- **Lightweight & Fast:** Runs directly in any modern web browser without requiring heavy installations or native desktop dependencies.
- **Browser-Based Control:** Uses custom JavaScript logic (`javaCtrl.js`) to handle media playback and YouTube API/player interactions.
- **Hosted via GitHub Pages:** Instantly accessible from both desktop and mobile browsers.
